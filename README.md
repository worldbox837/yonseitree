# 연세나무정신건강의학과 홈페이지 및 관리자 시스템

연세나무정신건강의학과(하남미사 본원 & 세종점) 공식 홈페이지 리뉴얼 프로젝트입니다.
기존 Google Sites의 한계를 개선하여 **타입 1 (내추럴 힐링 케어형: Warm & Mindful)** 감성 디자인과 편리한 관리자 모드를 제공합니다.

---

## 🌟 주요 기능 및 특징

### 1. 세련된 반응형 디자인 (타입 1: 내추럴 힐링 케어형)
- **따뜻한 톤앤매너**: 세이지 그린과 웜 아이보리 컬러를 활용하여 병원 방문의 심리적 문턱을 낮추고 치유의 공간을 표현
- **지점별 듀얼 허브**: 하남미사 본원과 세종 나성점의 진료시간, 위치, 의료진을 직관적으로 확인
- **모바일 최적화**: 스마트폰 방문자를 위한 하단 플로팅 바 (전화상담 📞, 길찾기 🗺️, 공식 블로그 📗)

### 2. 강력하고 간편한 관리자 모드 (`/admin`)
- **[조건 1] 의사 / 치료사 관리**:
  - 의사(원장단) 및 전문 치료사(임상심리전문가, 언어재활사) 신규 등록, 정보 수정, 삭제
  - 프로필 사진 업로드, 세부 전문 분야, 주요 약력 줄바꿈 편집, 정렬 순서 조정
- **[조건 1] 게시글 & 공지사항 관리**:
  - 공지사항, 방송/언론보도, 마음건강 칼럼 작성 및 수정, 삭제
  - 상단 고정(📌) 기능 및 대표 이미지 첨부
- **[조건 2] 유지보수가 쉬운 심플한 코드**:
  - 복잡한 대형 DB 설치 없이 가볍고 안전한 **JSON 파일 데이터 스토어** (`data/` 디렉터리) 채택
  - 폴더 통째로 복사하거나 백업할 수 있어 서버 이전 및 유지보수가 매우 용이
  - 의존성을 최소화하여 `node server.js` 하나로 즉시 구동
- **[조건 3] 첫 페이지의 배치 및 사진 등록 구조**:
  - **메인 히어로 사진 직접 등록/교체**: 1920x800 이상 고화질 사진 업로드 지원
  - **첫 페이지 섹션 노출 및 배치 순서(Order) 실시간 조절**:
    - [1] 상단 긴급 안내 배너 (초진 마감 안내 등)
    - [2] 메인 히어로 비주얼
    - [3] 지점별 빠른 현황 (하남/세종)
    - [4] 3대 핵심 가치
    - [5] 특화 진료과목
    - [6] 의료진 & 치료사진
    - [7] 방송 및 언론 보도 (우.아.달 리턴즈)
    - [8] 원내 시설 갤러리 (사진 등록)
    - [9] 최신 공지/칼럼
    - [10] 오시는 길 & 진료시간
    - 관리자 화면에서 순서 번호 입력 또는 ▲/▼ 버튼 클릭 한 번으로 첫 화면 배치 순서 변경
  - **원내 시설 사진 갤러리 관리**: 대기실, 진료실, 놀이치료실 사진 등록 및 삭제

## 🚀 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```
또는
```bash
node server.js
```

### 3. 접속 주소
- **사용자 홈페이지**: [http://localhost:3000](http://localhost:3000)
- **관리자 모드**: [http://localhost:3000/admin](http://localhost:3000/admin)
  - **초기 관리자 비밀번호**: `admin1234`

## 📁 디렉터리 구조

```text
Homepage_yonseitree/
├── server.js               # 웹 서버 진입점 (라우트 및 미들웨어)
├── package.json            # 프로젝트 설정 및 의존성
├── lib/
│   ├── db.js               # JSON 데이터베이스 CRUD 핸들러
│   └── upload.js           # 이미지 업로드 설정 (Multer)
├── data/                   # 데이터 저장소 (텍스트 메모장으로도 확인/백업 가능)
│   ├── settings.json       # 첫 페이지 설정, 배너, 섹션 순서, 지점 정보
│   ├── doctors.json        # 의료진 및 치료사진 데이터
│   ├── posts.json          # 게시글 및 공지사항 데이터
│   ├── subjects.json       # 진료과목 데이터
│   ├── gallery.json        # 시설 사진 갤러리 데이터
│   └── non-covered.json    # 비급여 항목 및 수수료 고지 데이터
├── public/
│   ├── images/             # 로고, 의료진 사진, 비급여 원본 등 정적 이미지
│   └── uploads/            # 관리자가 업로드한 이미지 파일
└── views/                  # EJS 뷰 템플릿
    ├── partials/           # 공통 헤더, 푸터, 관리자 네비게이션
    ├── index.ejs           # 첫 페이지 (동적 순서/사진 렌더링)
    ├── doctors.ejs         # 의료진 전체 소개 페이지
    ├── non-covered.ejs     # 비급여 항목 안내 페이지 (검색/필터/원본보기)
    ├── subjects.ejs        # 진료과목 상세 페이지
    ├── posts.ejs           # 공지/칼럼 목록
    ├── post-detail.ejs     # 게시글 상세
    ├── location.ejs        # 오시는 길 & 진료시간표
    └── admin/              # 관리자 모드 화면
        ├── login.ejs       # 관리자 로그인
        ├── dashboard.ejs   # 관리자 대시보드
        ├── homepage.ejs    # 첫 페이지 배치 및 사진 등록
        ├── doctors.ejs     # 의료진 목록
        ├── doctor-form.ejs # 의료진 등록/수정
        ├── posts.ejs       # 게시글 목록
        ├── post-form.ejs   # 게시글 등록/수정
        ├── gallery.ejs     # 시설 사진 등록
        └── branches.ejs    # 지점별 진료시간 & 실시간 접수 관리
```
